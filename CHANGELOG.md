# Changelog

## 1.0.0 — 2026-11-08

First public package.

- Personalization: similarity stays about the reference; personal fit is scored separately from known preferences, with sources disclosed.
- Requested differences (cheaper/free options, or a feature the reference lacks) no longer lower the similarity score.
- Reply and search in the user's language and named region.
- Quick / Standard / Deep depth modes, plus follow-up handling that reuses verified evidence.
- Trust check for clone and "free download" risks; table shows price; score bands and under-5-point ties.
- Intent presets with explicit weight precedence.
- Description rewritten around real trigger phrases; anti-jobs and a no-invent-prices rule added.
- README, MIT license, eval prompts, and Agent Skills `license` / `compatibility` frontmatter.
